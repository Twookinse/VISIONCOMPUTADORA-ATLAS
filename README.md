# VISIONCOMPUTADORA-ATLAS

Sistema de analisis por vision computacional para el karaoke Nex (La Paz). Utiliza camaras del local para extraer metricas operativas del negocio de forma automatica.

## Estructura del proyecto

- config/ - Carpeta destinada a la configuracion del sistema, como zonas ROI y parametros generales.
- models/pretrained/ - Carpeta destinada a los modelos YOLO preentrenados descargados.
- models/custom/ - Carpeta destinada a los modelos reentrenados con datos propios del negocio.
- src/detection/ - Carpeta destinada al codigo de deteccion de objetos y tracking.
- scripts/ - Carpeta destinada a los scripts de ejecucion y utilidades.
- videos/ - Carpeta destinada a los videos de prueba (no se suben al repositorio).
- tests/ - Carpeta destinada a las pruebas automatizadas.
- docs/ - Carpeta destinada a la documentacion del proyecto.
